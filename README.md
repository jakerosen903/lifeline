# Life Timeline

A voice-first app: you tell stories from your life, a timeline fills in, and over time it becomes a replayable autobiography in your own voice. Later, family members' timelines can be shared and fused, memory by memory.

Start with `CLAUDE.md`, then `docs/PRINCIPLES.md` and `docs/OVERVIEW.md`.

## Status

Design and grounding complete. Technical design in progress (`docs/TECHNICAL_DESIGN.md`). First task: the recording study in `docs/experiments/recording-study.md`.

## Stack

iOS native (Swift/SwiftUI) capture app · stateless server for the interviewer and extractor · web viewer deferred to Phase 3. See `docs/DECISIONS.md`.
