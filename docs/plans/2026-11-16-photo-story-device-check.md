# Photo story: device check

Run this on the iPhone with the photo-story build. Tick each line. Say what looks wrong. The simulator cannot show the system prompt or a real photo library, so these steps need a device.

1. [ ] Install the app fresh. Tap "Tell a story about a photo" in the record bar's menu. The explanation shows first. Tap "Continue". The system prompt shows. Answer "Allow Full Access". The grid shows "Your favorites", newest first. Tap a photo. The session starts with the photo on screen and the opening "Tell me about this one."
2. [ ] Install fresh again. Answer the prompt "Limit Access" and choose three photos. The grid shows "Photos you allowed" and only those three. "All photos" opens the system picker inside the same sheet, and it keeps its albums and search. Say how the inline picker looks next to the picker of "Add a photo".
3. [ ] Install fresh again. Answer "Don't Allow". The system picker opens at once in the same sheet. There is no error and no second prompt. Pick a photo. The session starts. Tap the entry again. The explanation does not show again, and the app does not ask again.
4. [ ] Change access in Settings between two stories (Full to Limited, then to None). Each next tap on the entry opens the right screen, with no error and no second prompt.
5. [ ] Make a Favorites album that holds a photo that is only in iCloud. Open the grid. The tile shows an image, not an empty square. Tap it. "Adding the photo…" shows while the original downloads. Then the session starts.
6. [ ] Pick an edited photo, a Live Photo and a RAW+JPEG photo. Each shows upright on the session screen and keeps its date in the caption.
7. [ ] Pick a scanned print. If it has a date, the card offers "The photo is dated {date}. Use that for when this happened?" Ignore the offer. Nothing changes and nothing asks again. Then tap "Use this date" on another story. The memory page shows the day and "from a photo".
8. [ ] Start a photo story with sound on. The photo is on screen while the app speaks the opening. The app asks nothing after the opening. Swap the opening for another. Say if the photo under a scene question looks wrong.
9. [ ] With VoiceOver, the grid reads each photo with its caption and nothing about what is in it. The session photo reads "Photo for this story" with its caption. On the card, "Remove" reads "Remove from {title}". Every control works with a swipe and a double tap.
10. [ ] Set the largest text size (Accessibility XXXL). On the session screen, the photo, the opening, Pause and Finish are all reachable and nothing clips. The same holds for the card on the landing.
11. [ ] Start a photo story and speak for a minute. Kill the app. Open it again. The landing for that session shows, with its photo card. Keep one memory. The photo is on it.
12. [ ] Tell two stories from the same Favorite. Each keeps the photo. Remove the photo from one memory. The other memory keeps it. Merge a second telling into the memory you removed it from. Say if the photo comes back (plan decision 4).
13. [ ] Delete a photo session from its landing. The dialog says "Its photo goes too." Confirm. When no page or memory held the photo, it is gone from the app at once. When a page held it, the page keeps it.
14. [ ] Look at a memory dated from a photo on the entity page and on the life strip of You. Say if "around {year}" instead of the day looks wrong.
15. [ ] Export a copy. Delete the app. Install it again and restore the copy. The photo story still shows its photo on the session's page, and its memories still hold it.
