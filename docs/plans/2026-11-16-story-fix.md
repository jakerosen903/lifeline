# A1: One Title, One Story Implementation Plan

**Goal:** A story title names one story. Accepting a story hint joins the story that already has the title. Copies made before this fix become one story. A chapter with no title and no memory is removed.

**Spec:** `docs/specs/2026-11-16-audit-data-fixes.md`, "A1: stories" and "A1: chapters". `docs/DECISIONS.md`, "Owner's calls on the audit data fixes" (duplicates are merged once, without a question, with one notice).

**Scope:** kit code only. No migration. No screen. This PR was written in a cloud session that cannot compile Swift; CI's `swift test` is the only check it had.

## Rulings

1. **The match key ships here, used by stories only.** Extractor v7 (A2) adopts it for places, things, chapters and collections, and adds the stored column.
2. **A hint on a memory that is already in a story.** When another, earlier story has the title, the memory's whole story joins it. The earlier story keeps its title and chapter.
3. **Ties on creation time.** `created_at` keeps milliseconds. The row order breaks a tie, so "the one made first" is always defined.
4. **The notice names the story when one title was repaired,** and counts the titles when there were several. Removed chapters are not in the notice: they held nothing.
5. **Empty untitled chapters are also removed when a memory changes chapter.** A memory that is deleted or merged away can still leave one behind; the launch repair removes it.
