# Sections — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app gets five labeled tabs (Timeline, People, Places, Things, You), a record bar above them that names the page the person is on, and a labeled Sessions button; each section then gets its own shape in a later PR.

**Architecture:** `AppModel` owns one `HomeViewModel` (the live session or landing) and the root is a `TabView` whose bottom accessory is the record bar. A page publishes its subject to `HomeViewModel.context`; a session started there stores the subject on its row (v12) and opens with a question about it. The first PR puts today's screens inside the tabs and changes no screen's content.

**Tech Stack:** Swift 6, SwiftUI on iOS 26 (`TabView` with `Tab`, `tabViewBottomAccessory`), GRDB 7 (migration v12), Swift Testing, XCUITest.

**Spec:** `docs/specs/2026-11-15-five-sections.md` (approved 2026-11-15; all five owner's calls decided as recommended). Read "Shell", "Build order" and "Constraints and hard limits" first. The audit it builds on is `docs/specs/2026-10-26-ui-audit.md`, which reaches `main` with PR #18.

This plan has two parts. Part 1 places every step among the work already in flight. Part 2 is the task list for the first PR, the shell. Each later PR gets its own task list, written when its turn comes, because each depends on what the one before it taught.

## Part 2 — PR S1: the shell

## Global Constraints

- Deployment target iOS 26.0. Verify `tabViewBottomAccessory` and `tabBarMinimizeBehavior` against the current SwiftUI documentation before use; do not rely on memory for their signatures.
- Tab titles, exact: "Timeline", "People", "Places", "Things", "You". Each tab has a symbol and its title.
- Record bar copy, exact: "Tell a story"; "Tell a story about {title}"; "Tell a story about yourself". The menu item is "Settle in".
- Subject opening copy, exact: "Tell me about {title}." and, for the owner, "Tell me something about yourself."
- Toolbar copy, exact: "Sessions" on Timeline; "Settings" on You; "Names you mentioned" in the People overflow menu.
- A session started from a page links nothing to the subject. Only the extractor links, from what the person says (non-negotiable 3).
- No new count, queue or "add" control on any tab (PRINCIPLES 9).
- Secondary text is `Theme.secondaryText` (#6D6153). `Theme.stone` is for hairlines only. Text contrast must be at least 4.5:1 on linen, sand and card.
- Every control is at least 44 by 44 points.
- Keep these accessibility identifiers: `home.start`, `home.settleIn`, `timeline.sessions`, `home.settings`, `home.people`, `timeline.showHidden`, `timeline.tagFilter`, `timeline.error`, `entities.row`, `entities.tagFilter`.
- This PR changes no screen's content beyond what a task names. The "About" section stays on Timeline.
- Kit tests: `cd ios/LifelineKit && swift test`. UI tests: `xcodebuild test -project ios/Lifeline.xcodeproj -scheme Lifeline -destination 'id=88EC5B09-3A30-4544-8145-F5246BB99AEE' -only-testing:LifelineUITests/<Class>`. Run `xcodegen generate` in `ios/` after adding app or UI-test files.
- Fixtures are invented; never a real person's words.

## Review Focus

1. The subject is deleted while its page's session is recording: the session row keeps recording and its subject becomes nil. Task 1 (`deletingTheSubjectKeepsTheSession`).
2. A second tap on the bar while a session is starting, from a different tab: one session only. Task 5 (`aSecondStartFromAnotherTabDoesNothing`).
3. The person leaves an entity page by switching tabs, not by going back: the bar must stop naming that page. Task 5 (`theBarForgetsThePageWhenTheTabChanges`).
4. A start error (microphone refused) while the person is on the Things tab: the message shows on the bar, on that tab. Task 5 (`aStartErrorShowsOnTheBarOnAnyTab`).
5. The app is killed mid-session and relaunched: the landing resumes over the tabs, whichever tab was last open. Task 4 (`anUnlandedSessionResumesOverTheTabs`).
