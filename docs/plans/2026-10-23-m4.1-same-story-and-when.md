# M4.1 Same Story and When — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A retold story is offered as "Same as X?" and merges on one tap; any memory can be given a date as said; the shelf rows show their two useful actions.

**Architecture:** A `MemoryMatcher` in the kit finds the nearest earlier memories with on-device sentence embeddings (cosine) and feeds them to the extractor's packet; the extractor's `same_as_memory_id` or a strong on-device match puts the line on the card. Merging is a kit action that adds a span to an existing memory (or folds one memory into another) with a snapshot for undo. Stated ranges are a new origin path on `TimeRange` that the resolver and the relative questions treat as settled.

**Tech Stack:** Swift 6, SwiftUI, GRDB 7 (migration v7), NaturalLanguage `NLEmbedding`, Swift Testing, XCUITest.

**Spec:** `docs/specs/2026-10-23-m4.1-same-story-and-when.md`

## Global Constraints

- Nothing merges and nothing is dated without a tap. Keep remains the default and primary button.
- Every range this milestone writes has `origin = .stated` and `evidenceText` set to the phrase shown.
- A memory excluded from AI gets no embedding row and is never retrieved or suggested. A hidden memory is never suggested on a card; the manual picker lists it only with `includeHidden: true`.
- Thresholds live in `MatchConfig`: `retrieveMin 0.55`, `retrieveCount 5`, `suggestMin 0.80`, `pickerCount 3`.
- Undo window for a merge is `CardHandler.undoWindow` (6 s), as for Dismiss.
- The embedder may return nil (asset missing, macOS `swift test`); every path must work with no vectors at all.
- Copy is fixed by the spec: "Same as **{title}**?", "recorded {Mon d}", "Same story", "Added to {title}.", "Undo", "Which one?", "None of these", "Same as another memory…", "Tell me when", "A year", "Around a year", "Between two years", "How old I was", "Add a date", "Add to a collection".
- Kit tests: `cd ios/LifelineKit && swift test`. UI tests: `xcodebuild test -project ios/Lifeline.xcodeproj -scheme Lifeline -destination 'id=88EC5B09-3A30-4544-8145-F5246BB99AEE' -only-testing:LifelineUITests/<Class>`; run `xcodegen generate` in `ios/` after adding app or UI-test files.
- Test fixtures are invented; never a real person's words.

## Review Focus

1. A merge target that is the memory itself, or a floating stand-in that has no real telling: `merge(a, into: a)` must throw, and the picker must never list the source. Task 4 (`mergingAMemoryIntoItselfThrows`), Task 6 (picker filter).
2. Two cards from one session both matched to the same memory: both merge, spans get orders 1 and 2, and deleting that session afterwards leaves the original memory with its order-0 span and nothing else. Task 4 (`twoCardsMergeIntoOneMemoryInOrder`, `deletingASessionRemovesOnlyItsSpans`).
3. The embedder returns nil for every text: no `memory_embedding` rows, backfill returns 0, retrieval returns nothing, the extractor path still suggests. Task 2 (`aNilEmbedderWritesNothingAndSuggestsNothing`), Task 3 (`extractorSameAsStillSuggestsWithoutVectors`).
4. A stated range with a conflicting anchor: the resolver and a later relative question leave it alone. Task 5 (`aStatedRangeSurvivesAResolverRun`, `aStatedRangeGetsNoRelativeQuestion`).
5. Undo after the window, or after the app relaunched: the notice is gone and the merge stands; a stale snapshot is never applied. Task 4 (`unmergeAfterAForeignChangeIsRefused`), Task 6 (notice timer).
