# M7 Elements — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Moments stay on the timeline; facts, feelings and goals leave it (PR A); then people, places, things and ideas become entities with pages, standing statements become their details, and domains become free-text tags (PR B).

**Architecture:** PR A adds one column, `memory.kind` (migration v9), and makes every timeline, chapter and question path read it: the pure `Resolver` and `RelativeQuestions` take the kind on `MemoryRef` and ask nothing about a non-moment, while placement is unchanged ("placed but hidden"). The app moves non-moments into an "About" section and adds "What is this?" to the Change sheet. PR B adds `entity`, `entity_span`, `moment_entity` and `domain_tag` (migration v9b), moves every reader and writer of `memory_person` and `memory_place` onto `moment_entity` (the person split), extends the extractor to v6 (`entity_refs`, `about_ref`, `domain_hint`, `thing` and `idea` mentions), and adds entity cards, pages, curiosity kinds and the packet section.

**Tech Stack:** Swift 6, SwiftUI, GRDB 7 (migrations v9, v9b), Swift Testing, XCUITest, Anthropic Messages API structured output (existing client).

**Spec:** `docs/specs/2026-10-24-m7-elements.md` (redlined 2026-10-25; read "Ship order" and "Owner's decisions").

## Global Constraints

- Moments: `event`, `other`. Non-moments: `fact`, `feeling`, `goal`. A memory with no payload or no card (a stand-in) is `event`.
- A non-moment is placed and its range is stored; no view shows it, no chapter range includes it, no `unresolved_anchor` curiosity or relative question is made about it, and "Add a date" / "Tell me when" are not offered on it.
- Nothing changes kind, type, entity link or tag without a tap. Keep includes only what the card shows.
- The app never asks for a date on an entity. "Add dates" on a Thing or Place page is the only path to a stated entity span.
- No curiosity question asks for a date about an entity, or asks the person to evaluate a belief or feeling. Fixed questions: "What do you remember first about {title}?", "Is there one time with {name} that stands out?", "Is there a moment that brought that to mind?".
- An idea title is a verbatim run of at most 8 of the person's words from the segment, or "An idea you mentioned on {date}" (date as `d MMMM`, e.g. "25 October").
- After v9b, no code reads or writes `memory_person`, `memory_place` or `place` except migration v9b. Enforced by a test that greps the kit's sources.
- Copy is fixed by the spec's Copy section.
- Kit tests: `cd ios/LifelineKit && swift test`. UI tests: `xcodebuild test -project ios/Lifeline.xcodeproj -scheme Lifeline -destination 'id=88EC5B09-3A30-4544-8145-F5246BB99AEE' -only-testing:LifelineUITests/<Class>`; run `xcodegen generate` in `ios/` after adding app or UI-test files.
- Fixtures are invented; never a real person's words.

## Review Focus

1. A memory changed from moment to fact while it is in a chapter and a story: it leaves the chapter's rows and the chapter's range is recomputed without it; it leaves the story row; changing it back restores both. Task A1 (`kindChangeRecomputesChapterRange`), Task A2 (UI: covered by `testFactKeptLandsUnderAbout` flipping back).
2. A fact that is the target of another memory's "before X" anchor: the other memory still places from it (placement is unchanged), and no question is asked about the fact itself. Task A1 (`factStillPlacesItsDependants`).
3. A v8 archive restored after v9/v9b: the migrations fill `kind` and copy links; a `.lifeline` copy from before M7 opens with every person and place link intact. Task B1 (`v9bOnAPopulatedV8KeepsEveryLink`).
4. Rename, merge (Same person) and delete of a person after the split: aliases, links and mentions follow; nothing is left pointing at a deleted entity. Task B2 (`renameMergeDeleteFollowTheEntity`).
5. An idea title the model wrote in its own words, or a title longer than 8 words: the validator replaces it with the dated default, never drops the card. Task B3 (`ideaTitleNotInTheSegmentFallsBack`).
