# Rulings — plan: docs/plans/2026-11-20-things-shelf.md

R1 (2026-11-20). S7 starts before the two-week watch in docs/plans/2026-11-15-sections.md ends. — Why: the owner said to continue with the next task, and was told of the rule. — Cost if wrong: the shelf is built before use of S2 to S6 could change it.
R2 (Task 2 review, 2026-11-20). `ThingQuote.choose` skips a detail that has no first telling, instead of treating it as safe. — Why: the heavy-session rule is a safety rule; when the app cannot tell which session a line came from, it must not show the line (it fails closed). A told detail always has a telling, so this hides nothing in a sound archive. — Cost if wrong: a detail with a missing telling row never gives a quote.
R3 (Task 4 review, 2026-11-20). The plan's assertion that a tile has no static texts in the XCUITest tree is replaced. It tests the automation tree, not what VoiceOver reads, and it fails on iOS 26 whatever grouping the view uses. The test now asserts: the tile is one button; its label is the title; its value is exactly the tile's other lines; no button is nested inside it; one element has that label. "VoiceOver reads a tile as one element" goes on the device checklist. — Why: People tiles are tested the same way. — Cost if wrong: a grouping fault that only VoiceOver shows is found on the device, not in CI.
R4 (final review, finding 1, 2026-11-20). A date that comes from a confirmed relation ("before the graduation") does not clear "Placed by a guess". The person confirmed the relation; the year inside it comes from the builder's slack. — Why: the period is then the app's arithmetic, not the person's word (non-negotiable 3). — Cost if wrong: a tile the person feels they dated still says "Placed by a guess".
R5 (final review, finding 2, 2026-11-20). This changes the spec's default 2. A thing's own stated span ("Add dates") places the thing whenever the span is dated. Dated moments place it only when it has no dated span. Before, the span was used only when no moment was dated, so one guessed moment could move a thing out of the years the person gave. — Why: the person is the author (P1); the person's statement about the thing beats the app's guess about one moment. — Cost if wrong: a thing with a stated span and a settled moment outside it sits in the span's period, not the moment's.
